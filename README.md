# GreenBite
A simple and responsive multi-page website built using HTML and CSS — featuring About, Contact, and Sign-up pages.

It includes multiple sections like Home, About, Contact, and Sign-up, designed to demonstrate basic front-end web development skills.

---

## ✨ Features  
- 🏠 **Home Page:** Main landing page with a clean layout  
- 👤 **About Page:** Brief info about the purpose or creator  
- 📞 **Contact Page:** Form or details to get in touch  
- 📝 **Sign-up Page:** Simple form layout  
- 💅 **Fully Responsive:** Works on different screen sizes  

---

## 🛠️ Tech Stack  
- **HTML5**  
- **CSS3**
